Retention & Backup

Local audit, alarm and downtime records can be retained for 1–3 years. Automated backups contain data/configuration JSON only; secret credentials in .env are intentionally excluded.

Recovery: the backup ZIP contains alarm events, acknowledgement state, logger settings, downtime history, calibration records, deviations, audit trail and report settings. Keep a separate protected backup of the server .env credentials.
