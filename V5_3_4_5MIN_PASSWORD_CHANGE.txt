PBF Rise Baking Burnaby Dashboard v6.0.0

UPDATES
1. Active temperature alarm reminders changed back to every 5 minutes.
   - First alarm notification: immediate.
   - Reminder while alarm remains active: every 5 minutes.
   - Recovery notification: once when temperature returns to normal.

2. Admin password can now be changed directly from the dashboard.
   Open:
       http://<mini-pc-ip>:8000/settings
   Login as admin, then use:
       ACCOUNT SECURITY -> Change Admin Password

3. Password-change security:
   - Current password is required.
   - New password must be at least 10 characters.
   - Password remains stored as a PBKDF2-SHA256 hash in .env.
   - Other active admin sessions are signed out after a password change.
   - Password changes are recorded in the Event Log.

4. The existing SET_ADMIN_PASSWORD.bat is still available as a recovery method
   if the admin password is forgotten. Run it directly on the mini-PC.

All existing features are retained:
- RUNNING / NOT IN USE alarm suppression
- protected alarm setpoint changes
- ntfy Windows certificate-store support
- Gmail notifications
- persistent Events
- 24/7 mini-PC Scheduled Task and watchdog
- industrial control-room dashboard
