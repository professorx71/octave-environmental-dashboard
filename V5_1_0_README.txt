PBF LI-COR Dashboard v5.1.0 — Multi-Page Graphic Dashboard

Pages:
1. /          Live dashboard with graphical temperature/humidity gauges
2. /trends    Temperature + RH historical graphs
3. /events    Persistent alarm/event history

Preserved:
- LI-COR live API
- Existing alarm limits
- Gmail alerts
- ntfy phone push alerts
- 5-minute active-alarm reminders
- Recovery alerts
- Server-side acknowledgement
- Persistent event history
- Logger communication health
- 24-hour CSV reports
- Pacific-time server reporting

INSTALL
1. Stop the previous dashboard.
2. Extract to a NEW folder.
3. Copy your private .env into this folder.
4. Run start_dashboard.bat.
5. Open http://localhost:8000
6. Press Ctrl+F5 once.

Never share your .env file.
