INSTALL
1. Stop all previous dashboard Command Prompt windows.
2. Extract this ZIP into a NEW folder.
3. Copy your existing private .env into the new folder.
4. If this is a new PC, run enable_lan_firewall.bat once as Administrator.
5. Run start_dashboard.bat.
6. Open http://localhost:8000 on the server PC.
7. For another device on the same LAN, use the LAN address printed by start_dashboard.bat.
8. Press Ctrl+F5 once after upgrading.

SECURITY
Do not share your .env file and do not expose TCP port 8000 directly to the public Internet.
